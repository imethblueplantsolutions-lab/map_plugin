Interactive Sri Lanka 25-district map plugin for AdForest (MyProperties.lk).

== Installation ==
1. Go to WordPress Admin -> Plugins -> Add New -> Upload Plugin.
2. Upload myproperties-listing-map.zip and click Activate.
3. The Sri Lanka 25-district map (lk.svg by SimpleMaps) is bundled and ready immediately.
4. Go to Listing Map in the left WordPress menu if you want to customize colors, behavior, or upload a custom lk.svg override.
5. Add the shortcode [myproperties_listing_map] to any page or Elementor Shortcode widget.
